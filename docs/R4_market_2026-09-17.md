## 1. iTerm2 代替の Mac ターミナル(2026)
- Ghostty: macOS側は Swift+AppKit+SwiftUI、コアは Zig(https://ghostty.org/docs/about)。最新タグ v1.3.1、1.3.0 は 2026-03-09 [API]。1.3.0 で「Claude Code regularly triggered in prior Ghostty releases」なメモリリーク修正、`notify-on-command-finish`、コマンドパレットの「jump to any running terminal by searching its title or working directory」、AppleScript 対応、tmux control mode は「not yet connected to the GUI」(https://ghostty.org/docs/install/release-notes/1-3-0)。リーク本体は「Claude Code's CLI produces a lot of multi-codepoint grapheme outputs」(https://mitchellh.com/writing/ghostty-memory-leak-fix)。報告例: 16GB機で71.49GB(https://github.com/ghostty-org/ghostty/issues/10289)。IME: 1.1.0 で日本語IMEの信頼性改善(https://www.publickey1.jp/blog/25/ghosttyghostty_110ime.html)、1.3.0 で「IME preedit text is now rendered with underlines」。macSKK で Ctrl-J が改行になる報告(https://zenn.dev/mtgto/articles/macskk-karabiner-settings-for-ghostty)。
- 常駐メモリ実測(第三者): 1タブ idle / 8タブ4時間: Alacritty 22/45MB、Ghostty 28/95MB、Kitty 35/110MB、iTerm2 85/290MB、Warp 210/380MB(https://dev.to/vibehackers/best-terminal-for-mac-in-2026-ghostty-kitty-wezterm-alacritty-warp-more-4pe6 2026-04)。別記事: Ghostty ~30、Kitty ~30、Alacritty ~20、WezTerm ~80-150、iTerm2 ~80-120MB(https://blog.luminoid.dev/Terminal-Emulator-Comparison-2026/ 2026-04-02)。
- Warp: Rust製・GPU描画(https://www.deployhq.com/guides/warp)。縦タブ、状態アイコン(working/blocked/completed/errored)、通知センター、Claude Code/Codex/Gemini CLI/OpenCode 同居(https://www.warp.dev/agents)。価格 Free 150→75クレジット/月、Build $20、Max $200(https://aitrendtool.com/tools/warp)。日本語未確定文字は 2025-07-28 修正(https://qiita.com/TomohiroSakai/items/dc890cb8daa931c8cb0d)。
- kitty: `kitten @ ls`(https://sw.kovidgoyal.net/kitty/remote-control/)。macOS CJK IME issue(https://github.com/kovidgoyal/kitty/issues/4062)。WezTerm: `wezterm cli list` が JSON(https://wezterm.org/cli/cli/list.html)。日本語インライン入力可(https://www.issoh.co.jp/tech/details/6174/)。Rio: Metal 化(https://rioterm.com/blog/2026/03/11/whats-coming-next)。Tabby: Electron(https://dashen-tech.com/en/dev-tools/terminal-emulator-comparison-2026/)。cmux: libghostty 上の Swift/AppKit、縦タブ・通知リング・Unix socket CLI、`cmux claude-teams`。★27,184、最終push 2026-09-17 [API](https://github.com/manaflow-ai/cmux)。
- 判断: 軽さだけなら Ghostty/cmux が 30MB 級で制御口も持つ。自作の差別化はキャンバスとタスク板。

## 3. 端末エミュレータ・ライブラリ
- SwiftTerm: v1.20.0 は 2026-08-18、「one last release before we land the breaking changes」。v1.19.0 で IME marked-text 改善 [API](https://github.com/migueldeicaza/SwiftTerm/releases)。
- libghostty: 2026-06 時点で「has not been tagged with a version yet」、C API alpha(https://github.com/ghostty-org/ghostty/discussions/11348)。Swift ラッパは Lakr233/libghostty-spm(★108、push 2026-09-17、MIT)。静的アーカイブ約141MB、全角行でカーソルずれ(https://dev.to/yuu1ch13/what-it-takes-to-embed-libghostty-in-a-swift-app-six-months-of-lessons-1m64)。
- Rio librio/rio-vt(2026-07-27)(https://rioterm.com/blog/2026/07/27/rio-vt-and-librio)。v0.5.27 のアセットに RioKit 無し [API]。要再確認。
- xterm.js+WebKit: 6.0.0(2025-12)。WKWebView の IME composition issue(https://github.com/xtermjs/xterm.js/issues/5894)。
- alacritty_terminal 0.26.0(2026-04-06)、DL 1,565,017。Swift からは FFI 自作(推測)。
- 判断: SwiftTerm 続行が最短。libghostty は未タグ、xterm.js は WKWebView IME が地雷。

## 4. 無限キャンバスをネイティブ Mac で
- SwiftUI Canvas「thousands of objects and run at 60fps」(https://designcode.io/swiftui-handbook-canvas/ 数値根拠なし)／「2-3 fps」報告(https://developer.apple.com/forums/thread/683293)。AppKit+CALayer 大量レイヤで劣化(https://developer.apple.com/forums/thread/95400)。数千ノードの体系的ベンチは無し。
- tldraw: `maxShapesPerPage: 4000`、ビューポートカリング(https://tldraw.dev/sdk-features/performance)。4.4(2026-02-19)で「up to 25x faster」(https://tldraw.dev/blog/tldraw-sdk-4.4)。excalidraw「8k it starts to struggle」(https://github.com/excalidraw/excalidraw/issues/10063)。
- 判断: 数十〜数百ノードなら限界に触れない。端末は WebKit に入れず SwiftTerm をネイティブで重ねる分離が IME 面で安全(推測)。
