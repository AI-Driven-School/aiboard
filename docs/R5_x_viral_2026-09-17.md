## 2. 横断パターン
- X の前に HN で火をつけ、X は5日以内に「Introducing」動画(cmux, Conductor)。両方やる。
- 1行目 = 一人称 "We made / Introducing" + 対象CLI名を列挙(Conductor, Nyx, cmux)。
- 動画は 26〜111秒、8秒でも回る(Gemini CLI 30秒, Nyx 26秒, Conductor 85秒, cmux 111秒, tldraw 8.4秒)。146秒(Warp)は薄い。
- 「困っている瞬間」を1文で(cmux「When Claude Code needs you, the pane glows blue and the sidebar tells you why」)。
- 創業者より有名人/第三者の引用が起点(Vibe Kanban 本人10 vs 第三者1,643、cmux Mitchell 991 が先)。
- README は「一文タグライン+スクショ+brew/npx 1行+Why」(cmux, Vibe Kanban)。
- 投稿時刻は 13〜19時 UTC の平日。
- 既定ON のテレメトリは HN で最上位批判(Vibe Kanban)。
