# 止まった時・並行する時の UI/UX（MECE・2026-09-19 実測に基づく）

「AI が止まる」「並行して動かす」場面を漏れなく数え上げ、**その時に人が何を失うか**から画面を決める。
数字はこの Mac の直近 30 日（会話ログ 6,726 本）を数えたもの。

## 原則（全ケース共通）

1. **止まった理由と、次の一手を 1 つだけ出す。** 選択肢を並べない。二番目以降は畳む。
2. **勝手に送らない・勝手に始めない。** 復旧は人が押した時だけ。例外は予約（本人が作ったもの）。
3. **同じ会話で戻す。** 別アカウントでも `--resume` で同じ記録の続きにする。新しい会話にしない。
4. **待たせない。** 状態の検出は裏で行い、盤は 2.5 秒で描き直す。
5. **黙って飛ばさない。** 走らなかった予約・届かなかった通知・落ちた検出は、理由を画面に残す。

## 分けかた（1 つの軸で漏れなく重なりなく）

**軸は「いま誰の番か」**。原因・操作は軸にしない（前の版は原因・実行形態・操作を混ぜていて MECE でなかった）。

| 誰の番 | 中身 | 何を出すか |
|---|---|---|
| **AI の番** | 作業中 / 一時的な失敗で自動再試行中（102 回） | 緑。**騒がない**。一時的な失敗は理由だけ小さく出す |
| **あなたの番・すぐ直せる** | 判断待ち（許可・信頼・初回確認）／返答済み | 赤・黄＋小窓＋音。一手は 1 つ |
| **あなたの番・直しが要る** | 認証 1,012（ログイン系 813／鍵の設定 199）・クレジット 11 | 赤「🔑」/「¥」＋直し方ごとに違う一手（ログインし直す／鍵の棚／請求ページ） |
| **時間が解く** | 5 時間枠 249・7 日枠 246 | 紫「⏸」＋解除時刻。一手は「別アカウントに移す」か「解除時刻に自動で続ける」 |
| **終わっている** | 正常終了 / 利用者が中断（Esc・Ctrl-C）/ プロセスが消えた | 灰。押せば同じ会話を再開 |
| **人でも AI でもない** | 予約が走らなかった・通知が届かない・盤サーバが落ちた | 上のバーと該当画面に理由（済: 見送り表示・通知の許可・iTerm 応答なし） |

## 決めたこと（なぜそうするか）

- **一時的な失敗（102 回）は騒がない。** Claude 自身が再試行して戻るので、赤くすると「狼が来た」になる。理由だけ小さく出す。
- **認証は直し方で分ける。** 「鍵が無効」(199) はログインし直しても直らない（設定の問題）ので、別の一手（鍵の棚）にする。

- **認証を最優先**にした。回数が最多（1,012 回）で、しかも**それまで盤に出ていなかった**＝利用者は「なぜか進まない」としか見えなかった。
- 上限の一手は「**移す**」か「**待つ**」の二択。移すのは別アカウント、待つのは解除時刻の予約。
  どちらも 1 押しで、押すまで何も起きない。
- クレジット切れに自動再開を出さない。**時間では解けない**ので、待たせると嘘になる。
- 同じ持ち場の並行は「気づける」までにする。衝突（同じファイルを同時に編集）の自動解決はしない。**人が判断する材料**（誰が何を触っているか）だけ出す。
- 通知・音・小窓は既存のものを使い、新しい通知の種類を増やさない（増やすと慣れて無視される）。

## いま作ってあるもの / まだのもの（2026-09-19 時点）

判断待ちの小窓と音・上限の別アカウント継続・予約の見送り表示・無人実行の畳み（判断待ちは畳まない）・
鍵の棚（KY-01）。

作った（2026-09-19 夜の追加）:
- **解除時刻に自動で続ける**（RS-01）: 上限のカードから 1 押しで「1 回だけの予約」を作り、解除時刻＋60 秒に
  **同じ会話を `--resume` で**開いて続ける。走ったら自分を止める。アプリが開いていない時は走らない（画面にそう書く）
- **同じ場所で並行**（PR-01）: 2 本以上動いているフォルダを snapshot に出し、カードに `⇉N`、
  会話ビューに相棒を並べて「同じファイルを触ると衝突します」。実機で `~` に 16 本・youtube-ai-pipeline に 2 本
- **会話の区切り**（TL-02）: 圧縮された所と、あなたが止めた所を、会話ビューに中央の線で出す

作った（2026-09-20）:
- **どこから再開すべきか**（RP-01）: 中断・停止した会話に、最後の依頼・そのあと済んだこと・**結果が返っていない操作**・
  あなたが止めた所・止まり方を出し、「この続きから再開」がその文面を添えて `--resume` する
- **別の機械のセッション**（MS-01）: `remote_hosts` の機械を ssh で読んで盤に枠で出す（**見るだけ**。送る・止めるはしない）。
  同じ機械の別名は 1 回だけ数え、hook が入っていない機械は記録の末尾から状態を推す
- **tmux**（LX-01）: mac でも tmux のパネルを拾い（tmux の中の claude は iTerm の一覧に出てこない）、
  盤から画面の文字を読み、キーを送れる。Linux の盤はこの道
