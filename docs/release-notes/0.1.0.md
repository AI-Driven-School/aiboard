最初の公開版。

- 盤: 動いている Claude Code / Codex のセッションを 1 枚の canvas に。赤=判断待ち・黄=あなたの番・緑=作業中、Dock に待っている数
- 端末は本物(libghostty)。iTerm で始めたセッションも tty で拾い、「右の端末で開く」でこのアプリに移せる
- 案件: 枠ごとに共通の指示と申し送りを持ち、開く端末すべてに渡す(Claude は system prompt、Codex は最初のメッセージ)。「任せる」は上限に当たっていない AI を選んで起こす
- 束ね方: 顧客・フォルダ・触っているファイルの置き場で自動に分け、名前と色と顧客は設定で上書きできる
- アカウント: 各 CLI 自身に聞いたログイン状態・プラン・上限・稼働本数。Claude の複数アカウント、Codex、Gemini、Grok、Cursor を一覧
- /loop の次の起床・予約(cron)・使った skill と MCP をカードに表示
- メモリ: 多い順の一覧、Esc で中断、2 回押しで終了
- 完全ローカル: 盤サーバは 127.0.0.1 のみ、ページは CSP で外部接続を禁止、外部送信ゼロを機械で証明するスクリプト付き
- 受け入れ試験 148 件(docs/uat/test-cases.md)
