最初の公開版。

- 盤: 動いている Claude Code / Codex のセッションを 1 枚の canvas に。赤=判断待ち・黄=あなたの番・緑=作業中、Dock に待っている数
- 端末は本物(libghostty)。iTerm で始めたセッションも tty で拾い、「右の端末で開く」でこのアプリに移せる
- 案件: 枠ごとに共通の指示と申し送りを持ち、開く端末すべてに渡す(Claude は system prompt、Codex は最初のメッセージ)。「任せる」は上限に当たっていない AI を選んで起こす
- 束ね方: 顧客・フォルダ・触っているファイルの置き場で自動に分け、名前と色と顧客は設定で上書きできる
- アカウント: 各 CLI 自身に聞いたログイン状態・プラン・上限・稼働本数。Claude の複数アカウント、Codex、Gemini、Grok、Cursor を一覧
- /loop の次の起床・予約(cron)・使った skill と MCP をカードに表示
- メモリ: 多い順の一覧、Esc で中断、2 回押しで終了
- 新しいフォルダで開いた claude が「このフォルダを信頼しますか」で止まっていることを見分け、盤から答えられる
- まとめ役: 長い依頼を「並行できる小さな仕事」に分ける案を出し、選んだ分だけ同時に起こす。同じ束として結果をまとめて見る
- 予約: 案件ごとに「毎朝 6:30 にこれを」を作れる。crontab は触らず、アプリが開いている間に走る。走った仕事は普通のカードとして出る
- 右の端末にタブ列: 端末ごとに盤と同じ名前・色・バッジ（判断待ち「!」）。押すとその端末になり、左の会話も追従する（入力先は端末のまま）。列が長ければ横に送れ、右クリックで「左で会話を開く」「端末を閉じる」。＋で新しいシェル
- 左右の結び付き: 左で会話を開くと右の端末も同じセッションになる（入力先は奪わない）。両方に同じ名前と色の札、右にある端末のカードには ⇄。右に無い会話は「右の端末には無い（iTerm / 背景）」と出る
- 会話はチャットの形（あなたは右・AI は左の吹き出し、道具の実行は中央の細い行）
- あなたが動かないと進まないカードにバッジ（判断待ち=赤「!」・あなたの番=黄「●」・上限=紫「⏸」）。枠の見出しには件数
- 判断待ちになったら音が鳴る（通知を切っていても鳴る・8 秒に 1 回まで・設定で切れる）
- 判断待ちが出たら、他のアプリの上に小窓が浮かぶ。1 / 2 / Esc と自由入力でその場で答えられる(通知を切っていても届く)
- 通知が macOS で止められていたら上のバーで知らせる(押すと設定画面へ)
- 「過去」の無人実行(claude -p)は持ち場 × 日で 1 枚に畳む。実測 6,391 件 → 束 68 枚・1 フレーム 8.3ms
- 「任せた仕事」は案件の画面に残り、その後に始まった会話と突き合わせて結果を出す
- 判定器（既定は規則）: 「最初に見せる判断待ち」「顧客の候補」のような選ぶだけの判断を、設定で手元のモデル（127.0.0.1）や外部の決定モデル（Jev 等）に替えられる。外部は既定で切・鍵は環境変数・伏せ字にした題名と先頭だけ・失敗時は規則へ戻す。証明スクリプトが状態を書く
- git のバッジ（既定は切）: ⎇ ブランチ（手元の git だけ）と PR #番号・状態（gh で GitHub に問い合わせ。別スイッチ）。カードと会話の見出しに出る
- 遠隔（既定は切）: 入れると同じ Wi-Fi の中からだけ、合言葉つきで「判断待ちの一覧と返事」だけができる小さな画面 /m が開く。終了・起動・設定は遠隔からは触れない
- 完全ローカル: 盤サーバは 127.0.0.1 のみ、ページは CSP で外部接続を禁止、外部送信ゼロを機械で証明するスクリプト付き
